# MedApp

## Run

```bash
dotnet run --project MedApp.AppHost
```

## Lite demo

A browser-only GitHub Pages demo with synthetic data: https://aliator.github.io/MedApp/

## Tech stack for the actual app

### Frontend

- React 19
- TypeScript
- Vite
- TanStack Router
- TanStack Query
- Astryx design system

### Backend

- .NET 10
- ASP.NET Core Web API
- MediatR
- FluentValidation
- ASP.NET Core Identity
- SignalR

### Data and storage

- SQL Server
- Entity Framework Core
- Azure Blob Storage

### Infrastructure

- Docker
- Helm
- Kubernetes
- .NET Aspire
- Argo CD
- GitHub Pages for the lite demo

### Testing

- NUnit
- Vitest
- Testing Library
- Playwright
